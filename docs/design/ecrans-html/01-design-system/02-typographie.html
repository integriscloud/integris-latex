Règles
16 px minimum pour le texte courant, 14 px pour le texte secondaire, 12 px seulement pour les métadonnées.
Interligne 1,5 pour le texte, 1,2 pour les titres, 1,7 dans l'éditeur.
Typographie française : espace insécable avant « : ; ! ? », guillemets « », nombres « 12 000 FCFA ».
Chiffres tabulaires (tnum) dans les prix, durées et numéros de ligne.
Repli système : si la police n'est pas encore chargée, on affiche system-ui sans bloquer (font-display: swap).
